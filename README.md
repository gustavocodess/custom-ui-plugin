# Builder.io Custom UI Plugin

The purpose of this plugin is to show some utilities on how to manipulate Builder UI and extend functionalities that are exposed from the web app. Custom plugins are available for Enterprise customers for specific use cases.

To know more visit <https://www.builder.io/c/docs/private-plugins-setup> or talk to one of our advisors at <https://builder.io/>

### install the dependencies

npm run install

### start the dev server

npm run start

### Go to your Builder.io account and install the plugin from the URL under your space settings

<http://localhost:1268/plugin-name.system.js?pluginId=@builder.io/plugin-name>
